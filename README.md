# Telegram-бот для проверки подписки на канал

Бот проверяет, подписан ли пользователь на ваш Telegram-канал:
- если подписан — отправляет ссылку;
- если не подписан — предлагает подписаться и повторить проверку.

## Быстрый старт

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте переменные окружения (или используйте `.env` на основе `.env.example`):
   - `BOT_TOKEN` — токен вашего бота;
   - `CHANNEL_USERNAME` — username канала (например, `@my_channel`);
   - `ACCESS_LINK` — ссылка, которую бот выдаёт подписчикам.
3. Добавьте бота в канал как администратора с правом просмотра участников.
4. Запустите:
   ```bash
   python telegram_sub_check_bot.py
   ```

## Команды бота
- `/start` — проверка подписки и выдача ссылки;
- `/help` — справка.
